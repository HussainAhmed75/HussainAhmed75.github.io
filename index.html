AutoML API

Upload a CSV or Excel file, pick the target column, and get back the best model and a full report — in one request.

  • Detects classification vs regression from the target's values, cleans the data and engineers date features.
  • Compares 10+ models with cross-validation and tunes the best one with Optuna (optional nested CV).
  • Writes a decisions log: every automatic choice is reported with its reason and can be overridden.
  • Returns a PDF report with charts or JSON; connected to n8n workflows through ngrok.
